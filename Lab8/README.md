# Lab 8 - Servidor - Get, Post e Template

## Como executar
1. Instale as dependências:
   ```bash
   npm install
   ```
2. Inicie o servidor (roda na porta 80):
   ```bash
   node servidor.js
   ```
3. Acesse no navegador:
   - `http://localhost/` -> Página `Projects.html`
   - `http://localhost/cadastra` -> Página `Cadastro.html`
   - `http://localhost/login` -> Página `Login.html`
